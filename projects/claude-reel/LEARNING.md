# LEARNING — Code-Rendered Motion Reel

A 15-second, 1080p60 motion-design showreel where every frame **and every sound** is generated by code.
This file is the playbook for doing it again, faster and better.

**Output:** `projects/claude-reel/out/claude-motion-reel-2026.mp4` (master, 59 MB) · `projects/claude-reel/out/claude-motion-reel-2026-web.mp4` (22 MB)

---

## 1. Quick start (reproduce from zero)

```bash
npm install                 # three, playwright-core, fontsource fonts
npm run stills              # 7 checkpoint PNGs → projects/claude-reel/out/stills/  (~10 s) — ALWAYS run before a full render
npm run render              # full 900-frame render, 8-sample motion blur → out/*.mp4  (~2 min on M2 Pro)
npm run preview             # live in-browser playback → http://localhost:5173/projects/claude-reel/ (click to play)
```

Requirements: Node 22+, Google Chrome installed (Playwright uses `channel: 'chrome'`), ffmpeg on PATH.

`render.mjs` flags: `--samples=N` (motion-blur sub-frames, default 8) · `--from=F --to=F` (frame range) ·
`--stills=a,b,c` (PNG stills only) · `--out=path.mp4`.

## 2. Workflow that worked

| # | Phase | What we did | Exit criterion |
|---|---|---|---|
| 1 | Probe environment | Checked node, ffmpeg, Chrome; **tested headless WebGL renderer string** | `ANGLE Metal Renderer: Apple M2 Pro` (GPU, not SwiftShader) |
| 2 | Lock the grid | Chose BPM so the piece divides cleanly: 128 BPM × 8 bars = **exactly 15.000 s**, 1 bar = 1 chapter | Math closes with no remainder |
| 3 | Write the score first | `src/score.js`: every kick, cut, bounce, keystroke as beat numbers | Visuals + audio both import it |
| 4 | Build engine, then scenes | Pipeline + HUD first, then one file per chapter | Each file < ~300 lines |
| 5 | Stills review | Rendered 26 key frames at `samples=1`, tiled into contact sheets, inspected visually | No broken frames |
| 6 | Fix → re-still loop | Patched only affected scenes, re-rendered only affected frames | Contact sheet clean |
| 7 | Transition strips | Low-sample preview video → 6-frame strips around every cut | Every cut lands on its beat |
| 8 | Audio QA | `ebur128` loudness + spectrogram + waveform images | Structure visible, loudness in range |
| 9 | Final render | 8-sample motion blur, bt709-tagged H.264 | ffprobe specs match |
| 10 | Verify sync | Extracted frames 111–114 around the drop | Frame 113 = impact (first frame after 1.875 s) |

**Key habit:** never judge by code — judge by rendered frames. Every real bug was found by looking at a contact sheet.

## 3. Architecture

```
index.html          importmap → three from node_modules
src/
  config.js         W/H/FPS/BPM/BEAT/BAR, palette, fonts, chapter captions
  util.js           easings, cubicBezier, spring, seeded RNG (mulberry32), pulse()
  score.js          ★ single source of timing truth (beats) — shared by audio + visuals
  fonts.js          FontFace loading (variable Inter Tight, Instrument Serif, JetBrains Mono)
  draw2d.js         per-glyph layout (kerning-safe), text scramble
  engine.js         frame pipeline + motion-blur accumulation
  post.js           composite + final GLSL
  hud.js            viewfinder overlay (auto-contrast)
  fx.js             global lens language: impacts, kick breathing, letterbox
  audio.js          full soundtrack via OfflineAudioContext + WAV encoder
  scenes/           type · knot · particles · world · liquid · easing · montage · signature
render.mjs          static server + headless Chrome + CDP capture → ffmpeg pipe
```

### Frame pipeline (per output frame)

```
for k in 0..samples-1 (sub-frames across a 180° shutter):
    3D scene → EffectComposer (RenderPass + UnrealBloom) → HalfFloat RT (linear HDR)
    2D canvas layer (type, UI, wipes) → CanvasTexture (premultiplied)
    COMPOSITE shader: ACES + sRGB on 3D, overlay 2D, CA / glitch / flash / zoom / letterbox
        → additively accumulated (weight 1/samples) into a HalfFloat target
FINAL shader (once): HUD auto-contrast overlay + film grain → screen
CDP screenshot (PNG) → ffmpeg stdin
```

### Scene contract

```js
export default {
  init(env),                                        // once, after fonts load
  three:  { start, end, update(t) → { scene, camera, bloom, exposure } },  // optional
  layers: [{ start, end, draw(ctx, t) }],           // optional 2D
  fx(t) → { ca, flash, zoom, sx, sy, glitch, letterbox, ... },             // optional
}
```
Time is always **global seconds**; scenes derive `gb = t / BEAT` (global beat). Pure functions of time → any frame renders in any order.

## 4. Concepts (the motion-design craft)

| Concept | Where | Why it matters |
|---|---|---|
| Squash, stretch, anticipation | Dot squashes before stretching; E squashes on landing | Classic animation principles signal craft instantly |
| Match cut | O's counter becomes a window into 3D; torus inherits the O | Continuity between 2D and 3D worlds |
| Parallax portal | 2D zoom ×48 (inCubic) vs 3D dolly 70→9 units; `setViewOffset` locks the 3D centre to the hole | Window moves faster than the world → depth |
| Continuity chain | dot → line → rails → word → O → torus → knot → particles → singularity → liquid → wipe → … → dot | Every scene is born from the last one; bookend dot |
| Morph targets on GPU | Particles seeded from the knot's exact surface at the cut frame | Seamless object → particle hand-off |
| Onion skin + spacing chart | Easing scene | Shows *timing* expertise, not just output |
| Cut to the beat | Word cards on 8ths, backgrounds on beats | Rhythm is visible |
| Silence before the hit | Beat 27 "(breathe)" + letterbox close | Contrast makes the finale land |
| Variable font axis | WEIGHT card sweeps wght 100→900 | Typography as motion |
| Text scramble decode | "MOTION DESIGNER" on end card | Signature UI motion trope |
| Foley locked to motion | Bounce "toks" at computed `outBounce` contact points, typing ticks per character | Sound design as proof of precision |

## 5. Decisions & rationale

| Decision | Chosen | Rejected | Why |
|---|---|---|---|
| Rendering approach | Deterministic code (three.js + canvas + GLSL) | AI video gen, Lottie, Hypit | Frame-exact control, reproducible, shows real skill |
| Timing model | Musical grid (beats) in one `score.js` | Seconds scattered per scene | Audio/visual sync by construction |
| Frame driver | `renderFrame(i)` pure function of time | Real-time `requestAnimationFrame` capture | Zero dropped frames, any render speed |
| Motion blur | 8 sub-frames, 180° shutter, **trailing** window `(t−shutter, t)` | Post-process blur | Real temporal blur for 2D + 3D alike; trailing window keeps half-frame cuts crisp |
| Colour pipeline | 3D linear HDR → ACES → sRGB in *our* shader; 2D stays sRGB | Three's OutputPass | Keeps 2D brand colours exact, tone-maps only 3D |
| HUD | Separate canvas, auto-contrast (INK/BONE by luminance) | Difference blend | Difference turned HUD cyan on orange — off-brand |
| Audio | WebAudio OfflineAudioContext, seeded noise | Stock track / AI music | Deterministic, synced to the same score, "every sound is code" |
| Capture | CDP `Page.captureScreenshot` `{optimizeForSpeed:true}` | `page.screenshot()` | 72 ms vs 349 ms per frame (lossless either way) |
| Encode | x264 CRF 17 + explicit bt709 matrix/tags | ffmpeg defaults | Defaults use BT.601 → reds shift |
| Fonts | Fontsource woff2 from node_modules | System fonts / Google CDN | Offline, deterministic, variable weight axis |
| Photosensitivity | Full-screen bg changes ≤ 1 per beat (≈2.1 Hz) | 8th-note colour strobes | Stays under the 3-flashes/sec guideline |
| Palette | INK `#0B0B0E` · BONE `#EFEAE0` · HOT `#FF4A1C` · VOLT `#2E5BFF` | Many colours | Limited palette reads as designed |
| Type system | Heavy grotesk + serif italic + mono | One family | Contrast = editorial sophistication |

## 7. Bugs found → root cause → prevention

| Symptom | Root cause | Fix | Prevention |
|---|---|---|---|
| Knot rendered as a blown-out white mirror, grey haze everywhere | Tube index winding was inverted → faces pointed inward → Fresnel at grazing = full mirror of a bright env | `idx.push(a, a+1, b, b, a+1, b+1)` | For custom geometry, derive face normal = e1×e2 on paper and compare with vertex normals; render a still immediately |
| Particle galaxy = white blob | 80k additive points with HDR ×2.6 colours + bloom threshold 0.35 | Alpha 0.18–0.48, colours ×1.1–1.5, density falloff, threshold 0.62 | Estimate overdraw: particles/unit² × px² footprint × alpha — keep < ~0.5 |
| Particle burst filled screen as noise | Camera inside the burst radius | Smaller burst (1.8–5.6), faster pull-back, near-plane fade `smoothstep(0.6, 2.8, depth)` | Keep camera distance > max explosion radius |
| Liquid shader pastel/washed | Too much BONE mix + high diffuse floor + ACES desaturating brights | Deeper shadows, less BONE, exposure 0.8, centre darkening behind text | Check text contrast on shader backgrounds at still time |
| Impact flash lingered as grey frames | Flash decay 80 ms at 0.5 | 45 ms at 0.45 | Flashes: peak ≤ 0.45, τ ≤ 50 ms |
| Intro almost silent | Normalisation to global peak crushed quiet intro | Boosted pad/riser/blip/ticks | Look at waveform image — every section should be visible |
| WEIGHT morph invisible | `outExpo` finished in 3 frames | `inOutCubic` over ~12 frames | Any "showcase" morph needs ≥ 10 frames |
| Full render slow (2.8 fps) | Playwright PNG screenshot 349 ms | CDP fast PNG | Benchmark each stage before optimising |
| Over-exposed 3D overall | RoomEnvironment is bright (area lights up to intensity 100) | `environmentIntensity` 0.42, bloom threshold 1.0 | Start env intensity ~0.4 with this pipeline |

## 8. Reusable techniques (copy these)

- **Beat-locked everything:** `gb = t / BEAT`; `seg(gb, a, b, ease)` gives eased progress through any beat window.
- **`pulse(t, times, decay)`**: exponential envelope since last event → kick-reactive scale, CA, FOV.
- **Kerning-safe per-glyph animation:** measure prefixes (`measureText(text.slice(0,i))`), not individual chars.
- **Portal hole:** fill INK, `destination-out` an ellipse at ~0.8× the O's ink box, then draw the glyph on top so the ring covers the excess.
- **Lock 3D to a 2D point:** `camera.setViewOffset(W, H, CX - x, CY - y, W, H)`.
- **Hand-off 3D → particles:** freeze the mesh state at the cut time in `init`, sample its surface, apply `matrixWorld`.
- **Diagonal band wipe:** N parallelograms, staggered `inOutQuart`, last band = next scene's background colour.
- **Deterministic audio:** seeded noise buffer, all events from `score.js`, render offline, normalise peak to 0.89.
- **Sidechain pump without a compressor:** automate a gain bus to 0.28 on each kick, ramp back over 240 ms.

## 9. Next time — do better

**Process**
1. Write `score.js` + an 8-row storyboard table before any scene code (worked; do it earlier and on paper).
2. Keep a `npm run stills` checkpoint list per scene from day one; render stills after *every* scene file.
3. Add an automated luminance check: fail if any still has mean luma > 0.8 or < 0.02 (would have caught the white knot + galaxy instantly).
4. Add an audio check script: per-bar RMS so quiet sections are caught numerically, not by eye.

**Craft upgrades to try**
- Camera jitter (`setViewOffset` sub-pixel) per motion-blur sample = free temporal anti-aliasing.
- Depth of field on the 3D chapters (BokehPass) for more cinematic focus pulls.
- A sting/logo sound designed around the dot bookend (currently a simple blip).
- Vertical 1080×1920 + square cuts from the same engine (only layout constants change).
- Replace the flat INK 3D background with a subtle gradient dome.

**Pipeline upgrades**
- Encode in-page with WebCodecs `VideoEncoder` to skip PNG round-trips entirely.
- Parallel render: split frame ranges across 2–3 Chrome pages, concat with ffmpeg.
- ProRes 4444 export option for handing to an editor.
